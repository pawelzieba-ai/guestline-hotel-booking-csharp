# Guestline Hotel Booking (C# Version)

Command-line tool to check hotel room availability and bookings.

## 🧩 Project Structure

- `Program.cs` – core CLI app logic (data models + execution)
- `hotels.json` – hotel metadata and room types
- `bookings.json` – sample booking entries

## 🚀 How to Run

Make sure you have .NET 6.0 SDK or newer.

Then execute the following:

```bash
dotnet run
